## Google Sheets
### 📦GameZone Orders eCommerce
[Project Link →](https://github.com/kelvinguo2711/gamezone-ecommerce-order-analysis)

#### Goal
Identify which products have the highest return rates, when return rate increased, whether specific regions, marketing channels or customer segments contributed to higher return rates.

#### Description
An end-to-end analysis of **eCommerce orders** from January 2019 to February 2021. The project involved data cleaning and standardizing the raw datasets, investigating data quality issues, performing EDA, and analyzing return patterns across products, time periods, regions, and marketing channels.

The analysis focuses on identifying significant changes in return behavior and translating the findings into potential business insights and recommendations.

#### Skills:
Data Cleaning · Data Quality · Exploratory Data Analysis (EDA) · Business Analysis · Trend Analysis · Return Rate Analysis · Google Sheets · Data Visualization
